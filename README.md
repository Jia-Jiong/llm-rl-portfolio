# LLM RL Portfolio

大模型强化学习学习与实验记录。以 [Datawhale Agentic RL Lab](https://datawhalechina.github.io/agentic-rl-lab/) 为参考，逐步实现奖励函数、组采样与评测，并记录实验配置和结果。
